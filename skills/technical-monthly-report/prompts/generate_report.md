# 报告生成提示模板

请根据以下结构化技术点生成中文 Markdown 技术月报。

## 强制章节

1. `## 已做任务`
2. `## 技术难点与解决方案`
3. `## 未来改进方向`

## 写作规则

- 只使用输入中存在的事实；
- 每个任务尽量说明产出物、指标或影响；
- 可以使用以下标签：`【主线实验】`、`【Bug修复】`、`【预研调研】`、`【评估体系建设】`；
- 技术难点必须同时说明问题、原因和解决方案；
- 如果证据不足，使用“可能”“初步观察”“待验证”等表述；
- 不要虚构日期、性能指标、工具调用结果或用户没有提供的成果；
- 输出纯 Markdown，不要额外解释。

## 输入

```json
{{analysis_notes}}
```
